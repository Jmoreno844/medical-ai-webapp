# Context pipeline (v1)

Parallel branch for doctor notes and patient documents. Runs independently from the transcript pipeline and merges at **generation**.

## Flow

```
doctor_note → decompose → claims ─┐
                                  ├→ classify_claims → generation
PDF → extract (text + LLM) → claims ┘
```

Transcript branch (unchanged):

```
filtering → clustering → classification → generation
```

## Modules

| Path | Role |
|---|---|
| [`decompose/`](decompose/) | Free-text doctor note → `ClinicalClaim[]` |
| [`extract/`](extract/) | PDF → text (`pdfplumber`) → facts → claims |
| [`classify_claims/`](classify_claims/) | Claims → template `section_ids` |
| [`session.py`](session.py) | Orchestrates all three steps |
| [`../cases/context/`](../cases/context/) | Synthetic fixtures (no PHI) |

Shared contracts: [`../common/context_claims.py`](../common/context_claims.py)

## Run

```bash
cd context_pipeline/decompose
make debug CASE_ID=case1 PROVIDER=openai

cd ../extract
make debug CASE_ID=case1 PROVIDER=openai

cd ../classify_claims
make debug-session CASE_ID=case1 \
  DECOMPOSE_RESULT=../decompose/results/<file>.json \
  EXTRACT_RESULT=../extract/results/<file>.json \
  PROVIDER=openai
```

Generation with both branches:

```bash
cd ../../generation
make debug-session SESSION_ID=case1 \
  CLASSIFICATION_RESULT=../classification/results/<file>.json \
  CLAIM_CLASSIFICATION_RESULT=../context_pipeline/classify_claims/results/<file>.json \
  PROMPT_VERSION=v002 \
  PROVIDER=openai
```
